# Общий список доменов для VPN

## Назначение

Один общий список публичных доменных имён для DNS-подписок AWG Manager.
В файле `domains.txt` — по одному домену на строку. Начальный набор состоит
из семи доменов, выбранных владельцем; дополнительные домены сервисов не добавлены.
В каждом менеджере выбирается собственный целевой VPN-туннель.

## Использование

Использовать проверенную RAW-ссылку непосредственно на `domains.txt`.
Подписка обновляется самим менеджером по его расписанию. Изменения общего файла
могут примениться ко всем подписанным устройствам; локальные правки менеджера
не отправляются обратно в репозиторий.

## Ограничения

Поддержка подписки и режима маршрутизации проверяется для установленной версии.
В NDMS домены сопоставляются по суффиксу: запись охватывает также свои поддомены.
Указание отдельного узла не добавляет остальные домены, необходимые всему сервису.
Общий список не заменяет настройку DNS, IPv6 и проверку фактического маршрута клиента.
Поведение при недоступности файла зависит от реализации менеджера; сохранение
последнего полного списка при ошибке загрузки не гарантируется.

В этот репозиторий предназначены только общие домены и их описание.
Конфигурации роутеров, VPN-ключи, пароли, внутренние адреса и домены управления
не должны попадать в публикуемые файлы.

Описание механизма: [DNS-маршрутизация AWG Manager](https://awgm.hoaxisr.ru/guide/dns-routing/).
